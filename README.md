# JCs_molbio

Journal club slide decks for molecular biology, built with [Quarto](https://quarto.org) (`revealjs`). Each journal club lives in its own subdirectory.

## Journal clubs

- [`Thielert2026/`](Thielert2026/) — RNA, protein and cell state: what does a correlation measure? A review of RNA–protein correlation, measurement accuracy and same-cell proteomics, centered on Thielert et al., bioRxiv v1 (2026).
